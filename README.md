# HER2 IHC reader study (demo)

**Open the viewer: https://jinxixiang.github.io/her2-reader-demo/**

Static viewer for a blinded HER2 immunohistochemistry reader study on IHC4BC breast cancer cases.
No account or installation is needed; open the link in Chrome, Edge, Firefox or Safari and follow the
instructions on the start page.

Demo build: the real IHC is shown in place of the virtual IHC, so scores entered here are for testing only.
